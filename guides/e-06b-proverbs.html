  1. Reduce the underlined sentence to its core idea in 4–6 words.
  2. Pre-guess the proverb before reading the options.
  3. Check each option’s meaning; examiners put a related-theme near-miss as the trap.

  6. Literal reading is always wrong (“empty containers”, “raining heavily”).

Concept notes – why proverbs are asked this way

A proverb is a fixed, figurative sentence. The question tests whether you can map a plain description to that figure. Examiners build distractors from the same theme (time, risk, money) so a half-known proverb fails.

Key contrasts: Make hay = grab a chance now; stitch in time = fix small problems early; look before you leap = think before acting; cross that bridge = do not worry early. All four concern timing but differ in intent.

Memory aids

  • Time trio: Hay = chance, Stitch = repair early, Bird = start early.
  • Risk pair: Look before you leap (think first) vs Eggs in one basket (spread risk) vs Bird in hand (keep the sure thing).
  • Fall words: Pride → fall; Fool → money parted; Forbidden → sweetest.
  • Sow = Reap: cause then result. Rust out = stay active. Devil = details.
  • Confusable pairs: Empty vessels (loud ignorant) vs Still waters run deep (quiet wise). Many hands (teamwork) vs Too many cooks (spoilt by crowd).

Trap alerts

  • “Do not delay when chance comes” → hay, not stitch. “Prevent small trouble growing” → stitch, not hay.
  • “Careful in advance” → look before you leap, not chickens-before-hatch (which is about premature counting).
  • “Hold small sure gain” → bird in hand, not “nothing ventured”.
  • “Too much ambition ruins” → pride goes before a fall, not “bite off more than you can chew” (which is about taking too much work).
  • “Strange preferences” → no accounting for taste, not “beauty is only skin deep”.
  • Meaning options that sound like a literal restatement are wrong.
  • Fill-up distractors: seed / bait / prey for worm.
